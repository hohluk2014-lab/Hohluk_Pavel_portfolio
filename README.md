# Портфолио Хохлюка Павла

Статический сайт без сборки: `index.html`, `assets/css`, `assets/js` и локальные фотографии.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите содержимое этой папки в ветку `main`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните настройки и дождитесь адреса Pages.

Сайт не требует Node.js, PHP или базы данных. Все пути относительные, поэтому он работает и на адресе вида `https://username.github.io/repository/`.

Видео открываются через Rutube. Локальные MP4 не нужны для публикации; обложки роликов сохранены в `assets/img`.

Для добавления фотографий мероприятия:

- положите JPG-файлы в папку события внутри `projects/foto/концерты и фестивали`;
- запустите `python tools/build-gallery.py`;
- проверьте `assets/js/content.js` и закоммитьте изменения.

В галерее показывается один кадр на событие. Остальные кадры той же папки доступны после открытия карточки и листаются стрелками или клавишами ←/→.
